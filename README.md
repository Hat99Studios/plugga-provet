# Plugga Provet – statisk webbplats

Detta är ett publiceringsklart statiskt underlag för Plugga Provet och appen Taxitrafiktillstånd. Sidan har inga beroenden, externa resurser, cookies eller JavaScript.

## Publicera med GitHub Pages senare

1. Skapa ett separat GitHub-repository och lägg innehållet i denna mapp i repositoryts rot.
2. Gå till **Settings → Pages** i repositoryt.
3. Välj publicering från önskad branch och roten (`/`).
4. GitHub visar sedan den offentliga adressen för sidan.

## App Store-länk

I `taxitrafiktillstand/index.html` ersätts texten **”App Store-länk kommer vid lansering”** med en riktig App Store-länk när appen har publicerats. Lägg inte in en URL före lanseringen.

## Kontrollera vid ändrad datahantering

Gå igenom `taxitrafiktillstand/integritet.html` om appen börjar:

- samla in eller skicka personuppgifter,
- använda analysverktyg, annonser, tredjepartstjänster eller cookies,
- lagra framsteg utanför användarens enhet,
- ändra hur köp eller supportärenden hanteras.
